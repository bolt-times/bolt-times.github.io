# Interviews

Save article drafts for the **Interviews** homepage section in this folder. Use descriptive filenames, such as `meet-the-art-club.md`.

To publish an approved draft on the website, add it to the `articles` array in [`../js/content.js`](../js/content.js) with category ID `interviews`. The site does not publish files from this folder automatically. Store photos in [`../assets/photos/`](../assets/photos/).
