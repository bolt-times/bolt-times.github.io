# Comic Strip

Save comic drafts and related notes for the **Comic Strip** homepage section in this folder. Use descriptive filenames, such as `the-missing-pencil.md`.

To publish an approved comic on the website, add it to the `articles` array in [`../js/content.js`](../js/content.js) with category ID `comics`. The site does not publish files from this folder automatically. Store comic images in [`../assets/photos/`](../assets/photos/).
