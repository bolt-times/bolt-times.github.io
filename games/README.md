# Games

Save game and puzzle drafts for the **Games** homepage section in this folder. Use descriptive filenames, such as `five-question-trivia.md`.

To publish an approved game on the website, add it to the `articles` array in [`../js/content.js`](../js/content.js) with category ID `games`. The site does not publish files from this folder automatically. Store related images in [`../assets/photos/`](../assets/photos/).
