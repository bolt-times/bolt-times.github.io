# Articles

Save article drafts for the **Articles** homepage section in this folder. Use descriptive filenames, such as `science-fair-recap.md`.

To publish an approved draft on the website, add it to the `articles` array in [`../js/content.js`](../js/content.js) with category ID `articles`. The site does not publish files from this folder automatically. Store photos in [`../assets/photos/`](../assets/photos/).
